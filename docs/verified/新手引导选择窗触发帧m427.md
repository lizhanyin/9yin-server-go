# 新手引导选择窗触发帧 m427（初出茅庐／再战江湖）

**日期**: 2026-11-27
**状态**: **真机已验证**——新号进新手副本后黑幕选择窗弹出，点「再战江湖」后跳过簇、解锁、
切出副本全链走通。
**问题**: 新号进新手副本后黑幕选择窗不弹，输入锁死（真机表现为「NPC 不物化、任务列表空」）。
此前按「属性 idx225 `FinishFreshmanRecStr` 是弹窗门控」在进场簇补发该属性，仍不弹。

---

## 一、结论

选择窗由服务端一帧显式请求：**S2C 自定义消息 427，零参数**。客户端引擎按消息号查到
`on_query_fresh_man`，调 lua 同名全局函数，对 `form_single_blackback` 做 `ShowModal`。

官服帧序（五个弹窗会话逐字节相同）：

| 帧 | 字节 | 含义 |
|---|---|---|
| m346 [2, 0] | `1e 03 00 02 5a 01 00 00 02 02 00 00 00 02 00 00 00 00` | `process_single_msg` 子型 2 → `form_single_check.custom_single_set_form(0)` |
| **m427 []** | `1e 01 00 02 ab 01 00 00` | **`on_query_fresh_man`：弹窗** |
| 0x10 CanntOperator=1 | `10 00 <obj> <own> 01 00 f9 00 01 00 00 00` | 锁输入，等点选（仅首次登录发） |

位置：客户端 op09（场景就绪）之后约 40 ms 的就绪簇，m390 [5, 0] 之前。首次登录的官服在
这一对之前还发 `SingleState=1 → m8 → m250 → m252`（关菜单、副本时限／次数提示窗）；
重登的待选号不发这四帧也照弹，所以触发只需要 m346 + m427。

`FinishFreshmanRecStr`（idx225）不是弹窗条件：引擎读它的地方只是 `form_main_map` 的新手
进度条，lua 另在跨服时读进 `game_config`。进场簇里那个初值帧照官服保留；就绪簇里
idx225 的 7 帧是和 m168 功能开启提示交错的一般下发。

### 客户端 lua

CN 2026 客户端（`AOW/9Yinch`，lua 包可反编译）：

```lua
function on_query_fresh_man(chander, arg_num, msg_type, ...)
  local dialog_black = nx_execute("util_gui", "util_get_form", "form_single_blackback", true, false)
  dialog_black:ShowModal()

```

窗体两个按钮：`btn_1` → `custom_send_single_step(4)`（初出茅庐），`btn_2` → `(5)`
（再战江湖）。上行是 0x0A 信封 `[972, double]`，不是 0x1E 帧。

AOW 客户端的 lua 字节码落盘加密（LuaQ 头后异或，密钥流含 `snailgam`、相位漂移，没解），
按名字 grep 搜不到——此前「现行 lua 包缺这条链」的判断依据不成立；真机已证实现行客户端
能弹。

## 三、实现

- `internal/entergen/guide.go`：`FreshmanQueryFrames()` ＝ m346 [2, 0] ＋ m427；订正
  `FinishFreshmanRecFrame` 与 m390 的注释。
- `internal/fssoloworld/guide.go`：`readyTail` 待选分支在锁输入之前发这两帧。官服首登多出的
  `SingleState / m8 / m250 / m252` 没补（重登会话不发也弹）。
- 已定档的角色不受影响。客户端 lua 没有这个函数时 m427 不起效。
  **2026-11-28 订正**：超时兜底（`NINEYIN_GUIDE_CHOICE_TIMEOUT`，缺省 20 秒按性别自动选）
  已整个去掉——黑幕窗已真机验证必弹，兜底反而把没操作的男号自动再战江湖传送出副本；
  官服也没有兜底，服务端一直等 `[972, 步骤]`（`gm guide` 仍是手工逃生口）。

测试：`TestFreshmanQueryFramesOfficial`（两帧逐字节对拍官服）、
`TestGuideReadyTailPendingLocksInput`、`TestGuideBirthStateEntersPending`（待选态就绪收尾
