# 坐骑与待机站姿链路（2026-11-05 GM「外观与坐骑」补全）

六区块一次补全：时装 / 时装·身份装发放 / 风物志卡牌（三者已有）+ **风物志头发 /
坐骑管理 / 待机站姿（持久化）**（本次新接）。本文只记后三者的协议依据与真机校准点。

## 1. 风物志头发（equip_hair）

- 前端 `equipSelectedHair()` → `command({action:'equip_hair', cardId})`；
  白名单 `GmRemote.validateCommand` + `LoginFlow.applyEquipHair`。
- 卡片口径：`SkinCatalog.Skin.hairOnly()` = Male/FemaleModelData 只含 Hat 部件
  （card.ini 27 张，如 1036 武道风物志-抱云揽月仙）。
- 语义 = equip_card 加两道闸：非纯发型卡明确拒绝；**同部件互斥**——挂载前摘掉
  已挂的其他 Hat-only 卡（一次一顶），其余部件挂载不动。存档同 role_skins。

## 2. 坐骑（mount_ride + C2S 243/266）

### 映射链（客户端资源取证）

```
tool_item.ini [ride_jh_whz_0001] script=Mount
  ArtPack=9583 ──→ itemartstatic.ini [9583].MaleModel = npc\ride_camel_0104   ← Mount 属性值
                └→ share/ride/new_ride.ini [9583] MountType/MultiRide/RideSkillID（兜底）
```

引擎按玩家属性 `Mount`(77, string) 非空 = 骑乘中，值即模型名（`ini\npc\<Mount>.ini`
加载，form_main_shortcut_ride.show_3D_mount 实证；menu_functions/neig_pk 以
`len(Mount)>0` 判骑乘）。

### 协议帧

| 通道 | 内容 |
| --- | --- |
| NewRideRec（官方 310，列型 [u32,u32,f64,u8]） | col0=坐骑包 id、col1=使用次数、col2=f64 到期（0=永久）、col3>0=当前选中；增量 = 0x12 倒序删行 + 0x11 整刷（CardRec 同方言） |
| 0x10 属性族 | `Mount`(string) / `NewRideID`(int, 1333) / `CurRiderType`(int, 82=MountType)；下马 = Mount 空串 + 双 0 |

坐骑总览 UI（form_new_allmount）绑 Mount + NewRideID + NewRideRec/RideCardRec；
骑乘快捷栏（form_main_shortcut_ride）由引擎 `server_start_ride(skill_list)` 驱动。

### 马背技能栏与骑乘技能（2026-11-11 官服方言定版；2026-11-12 真机勘误）

- **技能栏内容客户端自拼**：引擎 S2C 239 槽处理器（fxgamelogic.dll
  sub_1105BAE6 反汇编）读帧 int（包 id）经 NewRideManager（引擎组件，
  map<包id,记录>，由 NewRideRec 视图行回填）解析技能列表，按属性
  `Saddle` 空/非空追加 `,riding_saddle` / `,riding_kick_passenger`，再以
  skill_list 调 Lua `server_start_ride`——服务端 239 不发明技能列表。
- **2026-11-12 真机第一轮**：上马成功但按技能零 C2S（bar 未开）。客户端
  trace.log 实证 `custom msg type error [on_custom_new_ride]`——**menu2
  的 0x1E 窄串命名帧方言被客户端 OnCustom 拒**（分发器只认 int msgid
  首值，OnCustom 反汇编 12A20A30 定案），已删该帧。239 改发双 int
  [包id, 包id]：处理器 GetInt 的序基（0/1-based）静态无法定案，双覆盖
  两种序基都取到包 id（多余值引擎不读）。**待真机第二轮验证开栏。**
- **标准马三技能**（new_ride RideSkillID）：疾奔 `riding_jiben`（CD 60s）/
  冲刺 `riding_chongci`（CD 3s）/ 解除坐骑 `riding_dismount`。马背栏按键
  走标准 C2S 211 USE_SKILL（引擎 UseShortcutRideSkill → 同一发送通路）。
- **riding_start（骑术精通）= 主技能栏召唤技**（starter 五件套 21515）：
  客户端步行连发它的 211（真机 23:19 会话 50+ 次），已转 startSelectedMount
  按选中上马；骑乘中无操作。
- **受理簇（official_players 观战抓包三 jiben + 一 chongci 实证）**，
  无 msg20/284/CD 行/buff 帧，速度与栏位 CD 客户端本地结算：
  1. property `CurSkillTarget` = 自己；
  2. [仅 chongci] custom 24 `[obj 自己, 54, "hit", 窄串 HitEffect, obj 自己]`
     ——HitEffect 取四表链 skill_new→skill_static→skill_normal_varprop(
     Flow)→flow_config[Flow].HitEffect（chongci flow 439 =
     att_bossclone002_shouji01 逐位一致；jiben flow 1216 无 → 三验均无
     此帧）；
  3. custom 205 `[obj 自己, 窄串 技能ID, obj 自己]`（= skillHitConfirmFrame）；
  4. property `CurSkillTarget` = 0-0。
- **闸位勘误（根因）**：riding_* 无 zhaoshi 动作时间线，不在武学编译目录
  → 旧闸挂在 parseUseSkillCustom 之后实际从未到达，全部被当 unlearned 吞
  （「三个技能没做」的直接原因）。现先于目录闸分流：dismount 族转下马、
  步行发骑乘技/骑乘发非白名单技忽略、其余发受理簇（mount_skills.go）。
- effects_data 的 `buf_riding_chongci` 1000ms 自增益是 INI 约定推导
  （tools/skill-data 生成物），抓包无 m169/槽帧实证——照官服不补发。

### 服务端行为

- **GM `mount_ride(mountConfig)`**：道具 → 包 → 未拥有自动补行（永久口径）→ 骑乘；
  **再点同骑 = 下马**（拥有保留）。`MountStore`（data/坐骑.json + role_mounts，
  admin/sql/0011）。使用坐骑道具不消耗（GM 口径）。
- **C2S 243 `custom_ride(int)`**：引擎骑乘键（>0=骑当前选中 / 0=下马）。
- **C2S 266 `custom_new_ride(sub,...)`**：ride_util 子令 1=USE_ITEM / 2=SELECT_RIDE，
  参数形状引擎侧不可见——tolerant 按「tag6/7 串=config / tag2 int=包 id」命中，
  不命中落 `shape probe` INFO（真机形状钓取口）。
- **登录回填**：ClientReady 推 NewRideRec 行 + NewRideID；**Mount 不跨登录保持**
  （重登即步行），骑乘键/坐骑道具再上马。切图重入（0x0C 清行）后整表重放。
- **PanelState.mount**：骑乘中写活值，防全量 0x10 用空串清骑乘态
  （domainProperties 本就预留该字段）。

## 3. 待机站姿（idle_stance_set，持久化）

- 站姿 = 引擎基座动作（`ini/b_action_index.ini` 节名，如 stand / khbd_stand_01 /
  TJstand；GmCatalog.idleStances 按「节名含 stand」给候选）。
- **下发通道：0x10 属性 `PlayActionName`(821, string)**——官服 0x09 真机表在册。
  备用通道（真机不生效时切换）：S2C 命名 custom `on_body_change(ntype=1, action)`
  → 客户端 `action:BlendAction(player_visual, action_id, false, false)`
  （`CustomMessages.modernCustomCommandMessage` 已具备该编码）。
- **持久化**：`IdleStanceStore`（data/待机站姿.json + role_idle_stance，0011）。
- **回站保持**：1s faculty ticker 内 4s 一拍——仅闲时（effectiveLogicState==0 且
  非 riding）重推；受击/挖矿/技能结束打断后 ≤4s 自愈回所选站姿；ClientReady 首推、
  切图重入复位首推门。**恢复当前站姿按钮** = `idle_stance_set` 空参（重推不改档）。
