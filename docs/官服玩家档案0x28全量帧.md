# 官服玩家档案 0x28 全量帧解析（2026-11-12）

> **结论一句话**：登录进场簇里那条 5KB 级的 0x28 大帧是**玩家自身的全量档案帧**
> ——布局与 NPC 详情 0x28 v3 同构（`[obj][own][变换块][count][字段×N]`），
> 但字段数 292~393（六包实测：c 295 / 登陆 296 / 登陆2 297 / 登陆-all 299 /
> k 393），字段方言 = `[idx u16][值按 0x09 表列型]`，串 = `[len u32 含NUL][GBK+NUL]`，
> 长串为 NUL 连接的串数组；尾部嵌套携带玩家 obj/own 的子记录块与技能行
> （ConfigID+16 列模板）。**官服全部用 mode=0x47（LZ）发送；解出字段清单后
> 本服可直接走 mode=0x46 纯 memcpy 明文路径下发**（npcDetail0x28V3Frame 同族）。

承接：`docs/官服0x29批量预载通道解析.md`（登录簇全景）、
`docs/op28-fxnet2-lz-decoder.md`（0x47/0x46 族）、`docs/官服模式NPC渲染收束.md`。

时序锚（登陆-all）：`[0x0B 玩家进场] → [0x14/0x11 ×3] → [0x29×3 记录批] →
[0x14/0x11] → **[0x28 玩家档案]** → [0x14 sub1/0x11 玩家视图行爆发…]`。
紧随其后的 0x14/0x11 用**同一 obj/own**（0x1105c0e3/0x03defbae）——档案帧
先行建立实体，视图行随后挂靠。k#1978 证明**换景/重进场时整帧重发**（obj 换新、
字段区字节级一致、count-1=少一个 idx）。

变换块：posA=登录/换景落点（六包 327~939 均为合理场景坐标）、posB 全零、
**scale=0**（玩家模型缩放客户端本地定，与 NPC 帧 1.25/1.28/5.0 不同）。

## 二、解码链路（三道坎，工具已固化）

1. **TCP 重组**：pcaplib.build_streams 是到达序裸拼接——登陆-all 的 7074 流
   ①端口复用两条连接混在同一四元组（ISN 大跳变）②2824B 迟到重传把 3203B
   的档案帧撑成 6027B 假帧。须按 seq 重组（epoch 切分 + 重叠去重）。
2. **LZ 池种子**：mode=0x47 族共享池。**新发现：非 0x27-0x30 族帧的原始明文
   也按 4B 滑窗注册进池**（idx=((v>>12)^v)&0xfff）——World2.register_raw
   按线序喂入后族帧通过率 71→135 帧中 99 ok。残余 miss = 客户端本地种子
   （0x29 文档 §3.1 结论不变）。
3. **跨包拼合**：同一档案帧在多包重复、池轨迹不同 → 各包 partial 互补。
   k#1978 因会话中途池已喂饱而**全解**（5763B 完整明文）——本帧族唯一全量样本。

工具：`tools/op46_profile_stitch.py`（重组+World2+全规则走查），
`tools/op46_player_profile.py`（v2 扫描器）。明文样本：
`tmp/profile_k78_fields.txt`（k#1978 全字段走查）。

## 三、帧布局（帧头 + 体头）

```
[0]=0x28 [1]=0x47/0x46 [2:6]=len-1 u32 [6:10]=明文体长 u32 [10:]=明文体
明文体:
  [0:4]   obj u32（玩家实体 id）
  [4:8]   own u32
  [8:60]  变换块 13×f32：posA x,y,z,yaw | posB(全零) | scale=0 | 保留0
  [60:62] u16 字段总数 count
  [62:]   字段区（见 §四）
```

## 四、字段方言

**主体 = `[idx u16 LE][值]`，值宽按 0x09 表列型**：
t1=u8 t2=u16 t3=u32 t4=u64 t5=f32 **t6=8B(f64)**（tiaozhan_probe 0x10 方言
6:8 一致，HomeFengShuiDate=42952.0=日期序列值实证）t9=obj u32；
**t7=[len u32 含NUL][GBK+NUL]、t8 同（宽串）**。

六帧 43 个基础字段全部按此走查精确对齐；官读编码器另有四种**可绕开的捷径**
（本服 0x46 明文发射无需复刻，客户端明文路径都收）：

| 捷径 | 样本 | 说明 |
|---|---|---|
| len=0 → cstring | Book：`af 00|00000000|book1\0` | 0 长时直接 NUL 结尾串。明文路径直接写真实 len 即可 |
| `[idx_lo][FF]` | 登陆-all：`0a ff`（=idx10+flag） | idx<256 时高字节位被挪作 flag。明文路径写 `0a 00` 即可（k15/c/登陆 官方自己也写 00） |
| `[00 连跑][01 00]` 标记 | BaseFace 后 46B、技能行间 | 分节/行界标记，语义未定。NPC 0x46 明文帧**无此物**——明文路径可省 |
| 串数组 NUL 槽增量块 | ShortcutKey 176B 主段+续段 | 0x29 文档余项1 同源的行级增量串编码。明文路径可发完整串数组（len=NUL 连接总长） |

另：**字段可缺席**（k#1978 相对 k#15 少 idx162 IsCheckPass）——按需稀疏。
