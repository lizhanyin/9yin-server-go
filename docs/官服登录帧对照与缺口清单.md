# 官服登录帧对照与缺口清单（c.pcapng ↔ protocol-probe）

> 基准：`docs/official/官服抓包交互时间线分析.md` 及三份附录（a–i.pcapng，2026-11-08 抓取）。
> 登录样本为 **c.pcapng**（会话①断线重连，唯一带完整握手的段：C2S op04 → 全量快照 → ClientReady → 技能大簇 → 进场物化，0–7.8s）。
> 我方实现：`cmd/protocol-probe`（main.go handle() 主循环）。本文逐帧对照，标出：**[缺失]**（我们从不发送）、**[数据差异]**（发送但内容/形态与官服不同）、**[未应答]**（客户端发了、官服有回应、我们没有）、**[对齐]**（已一致或刻意等价）。
> 语义未定位的帧一律保留并注明「未定位」——不影响收录。
>
> ⚠️ 总前提：本服面向 fork 客户端、以真机实测可用为准；官服（7071/7072/7074 线）方言与 fork 抓包存在已知分叉。凡属「刻意不同」的项（代码注释里有实证记录）在表中注明，不算缺陷。

## 一、登录流程形态差异（宏观）

| 环节 | 官服（c.pcapng 重连） | 我方（protocol-probe） |
|---|---|---|
| 连接后首帧 | （重连场景）客户端直接发 **op04 len=84** 携带会话恢复信息 | 客户端先发 op02 账号登录 → 我方回 0x04 角色列表（main.go:1809）→ 客户端再发 op04 选角（main.go:1857）。首连多一个账号阶段 |
| 会话票据 | op04 后立即回 **op32 len=1026**（"218:#INNER…" 票据） | **无 op32**。全仓无 0x20/0x32 服务端帧（internal/transport 仅帧编解码） |
| 对钟 | C2S m924（~1s）→ S2C **m294 应答**（回显 client_ms + 玩家 obj + unix 秒 + uptime 天数） | **不答 m924**；改为连接起 1s 周期单方面推 m294（main.go:455），值列格式不同（见 §四-1） |
| 登录握手 | C2S m9（密钥对+版本 11005+MD5，6s 周期，**官服也无逐次应答**） | 不处理=与官服行为一致 **[对齐]** |
| 表下发 | 0x09 属性表（2433 项）→ 0x0A 记录表（**单帧 10429B / 446 schema**） | 0x09（2370 项）→ 0x0A（447 schema 10449B）→ **再发 0x0A 镜像 10429B**（home_records_frame.go，刻意：客户端取其帧头 16B 作 C2S 0x0A 信封头回显） |
| 就绪屏障 | C2S op09 len=1（ClientReady）→ 技能/视图大簇 | 同形：0x09 分支（main.go:2107）**[对齐]** |

### 8.1 S2C 寻址模型修正（重要）

Java 参考服 `CustomMessages.java` 注释与 modern 客户端互证：S2C custom 有**两种互斥寻址**，由首值线型决定——
- 首值 tag2(int) = **数字路由**（引擎 exe 内 ID→handler 表分发，官服抓包主体）；
- 首值 tag6(string) = **命令名路由**（引擎直接调 custom_handler.lua 同名函数，"现代 0x27 壳"）。

C2S/S2S **ID 命名空间按方向独立**：S2C m199=排行榜应答、m200=府邸/GUID 应答，与 C2S m199=内功绑定、m200/201=快捷键互不相干。

## 十、IDA 实证轮（FsGame-timeprobe.dll.i64，2026-11-10 第四轮）

### 10.1 S2C custom 架构定性（决定性）

`sub_1033B1E0`（已命名 **CustomSysInfoByKen**）反编译实锤：构造 `TVarList = ["sysinfo", type, string_id, extra]` 后走虚表 **+0x5C4** 的统一 SendCustom 发送。即：

- **2014 协议 S2C custom = 纯命令名寻址**（首值是 "sysinfo"/"speech" 等字符串，引擎/客户端按名分发）；
- **2026 官服抓包的数字 ID（m1/m98/m386…）是后续版本给命令名分配的编号**——`m1 ↔ "sysinfo"` 载荷形态逐位吻合（官服 `m1 [2,"8066"]` = `["sysinfo", 2, "8066"]`）；
- 名→数字 ID 的注册表**不在 2014 版内**（全库无指向命令名字符串的指针表；924/431/211 等 ID 也无任何立即数引用）→ 剩余未定位数字 ID（m98/m228/m648 等）需 **2026 版服务端引擎或现代客户端 fxgamelogic.dll** 才能闭环。
