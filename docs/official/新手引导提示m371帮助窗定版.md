## 一、结论

现行客户端的「引导提示」是**帮助窗**：箭头动画指向某个控件＋一行提示文案（如
「右键点击行囊中的技能书学习」）。它只由服务端 **S2C m371** 触发，本服此前从未发过——
官服整场引导发了 23 条，每条挂在一个明确的服务端事件上（发书、学会、某个对话步、
接取）。`HelpStepID`/m950 链只推进步骤号，本身不出任何界面。

## 二、证据

### 2.1 客户端机制

- **handler**：S2C 371 → lua `on_new_player_guid`（handler 表两套同号；372 是它的江湖
  变体 `on_jianghu_guide`）→ 延 0.5s 调
  `form_main_helper_manager.open_helper_form(帮助类型, "1"[, 参数])`。
- **数据**：客户端静态配置 `ini\new_helper\player_helper.ini`（帮助类型 → 节点）＋
  `helper_info.ini`（节点：`open_form` / `focus_control` 指向哪个控件 / `ani_image`
  箭头动画 / `text`=desc_xsyd_* 文案）。参数是定位用的配置 ID（背包里那一本书、
  武学）。帮助类型 id 在客户端 lua 与任务数据里零引用——是服务端私有配置。
- **老机制已死**：`freshmanhelp.ini` 的 `tip/textinfo/tipTime/tipphoto/autoshow` 键在
  现行客户端全部 2297 个 lua 字节码与所有引擎 dll 里零引用，
  `freshman_help.auto_show_form` 没有调用者。（现行 `freshman_help.lua` 与仓内旧反
  编译树逐行一致，已用 unluac 复核。）
