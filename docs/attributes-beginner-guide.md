## 一、伤害类型：外功与内功

与其它游戏"物理攻击 / 魔法攻击"的划分对应，九阴的伤害分两大类：

- **外功伤害**
- **内功伤害**——细分为四小类：**阴 / 柔 / 阳 / 刚**

> 📷 图（未提供）：两张招式描述截图，红线分别标注"造成 xxx 阴伤害""造成 xxx 外功伤害"。描述为【阴伤害】者属内功伤害；【柔伤害】【阳伤害】【刚伤害】同理，均为内功伤害。外功伤害则显而易见。

**防御减免对应关系**：内功伤害被对手对应的属性防御减免——阴伤害被阴防御减免，阳伤害被阳防御减免；外功伤害则统一被外功防御减免。

## 三、五维

九阴人物有五个基础属性（五维），**由当前运行的内功决定**（与别的游戏不同，详见第五节）：

| 五维 | 主要提供 |
|---|---|
| 臂力 | 近身威力、外功暴击、少量气血 |
| 身法 | 远程威力、外功命中、闪避 |
| 内息 | 内功威力、内力 |
| 罡气 | 内功命中、内功暴击、少量内功防御 |
| 体魄 | 气血、封劲、招架值 |

## 四、衍生属性详解

| 属性 | 主要来源 | 作用 |
|---|---|---|
| 气血 | 内功（大量）、体魄、臂力 | 生命值 |
| 内力 | 内功（大量）、内息 | 使用大部分招式都要消耗内力 |
| 近身威力 | 臂力 | 为带红色数字的招式提供额外伤害加成；观察所有招式，凡有红色数字者，近身威力均为其提供额外加成伤害 |
| 内功威力 | 内息 | 同上，对应蓝色数字 |
| 远程威力 | 身法 | 同上，对应绿色数字 |
| 外功暴击 | 臂力 | 根据对手封劲经复杂计算后，决定外功招式的基础暴击率（上限 15%，下限 0） |
| 外功命中 | 身法 | 根据对手闪避，决定外功招式命中率 |
| 内功暴击 | 罡气 | 效果与外功暴击基本一致 |
| 内功命中 | 罡气 | 根据对手闪避，决定内功招式命中率 |
| 封劲 | 体魄 | 降低自己被暴击的概率（内外功通用） |
| 闪避 | 身法 | 降低自己被命中的概率（内外功通用） |
| 外功防御 | 装备为主 | 降低所受外功伤害 |
| 内功防御 | 装备、经脉、内功 | 细分阴 / 柔 / 阳 / 刚防御，降低所受对应属性伤害 |

> 颜色对照——**黄色**＝基础伤害；**红色**＝近身威力的额外加成；**蓝色**＝内功威力加成；**绿色**＝远程威力加成（截图上没有，记住颜色即可）。

## 五、内功：五维的来源

- 内功是角色的核心，决定人物的基础属性、气血、内力、五维等，并提供一个**常驻的内功特效**。

- 内功**同时只能运行一个**；运行时获得其提供的大量属性，卸下后就会"变回一个小菜鸡"。
- 内功分三大类：**阴柔 / 阳刚 / 太极**。如【六合经】右上角标识表明它属阴柔内功。

> 招式描述，右上角有两个小字"实""阴"。"阴"代表该招式所属套路为阴柔；"实"为**招式类型**——招式分**实招**与**虚招**：实招只造成伤害，虚招用于破格挡（原文未解释，用户补充）。太极属性的标志不是文字，而是一个小太极图。

- 内功类别的两个作用：一是**决定装备**（原文留到第三篇讲）；二是**影响招式伤害**——运行内功与套路属性匹配时的加成：

| 运行内功 \ 套路 | 阴柔套路 | 阳刚套路 | 太极套路 |
|---|---|---|---|
| 阴柔内功 | **+20%** | 无加成 | +16% |
| 阳刚内功 | 无加成 | **+20%** | +16% |
| 太极内功 | +16% | +16% | +16% |

（已确认口径）阴柔↔阳刚互搭不在加成之列——"阴柔用阳刚也不是不行，就是会少 20% 的伤害"；太极内功对阴柔 / 阳刚 / 太极套路均 +16%（属性篇原文"太极套路 +20%"系误记，按伤害计算篇 6.1 口径修正）。

因此运行的内功基本决定了应使用对应属性的套路招式；太极内功与太极套路搭谁都吃 +16%，最万金油。

### 6.2 防御属性解析（原第 2 节）

**外功防御**

- 来源：装备与武学。装备每 +1 点外功防御＝+1 点外防，数值看着低，但勿小看。
- 机制：类似《英雄联盟》的**临界点减伤**——防御达到阈值档位才提供相应减免；9999 防与 10000 防相差整整 1% 减伤，而 0 防与 1 防之间几乎没有差别。
- 参考阈值：**外防 1 万＝减伤 50%；2 万＝减伤 75%**（原文仅列此两档）。

**内功防御**

- 来源：内功、经脉、佩戴的首饰，也有部分武学加内防。
- 同为临界点减伤，但阈值为外防的 **1/10**：**内防 1000＝减伤 50%；2000＝减伤 75%**。
- 内防细分阴 / 柔 / 阳 / 刚，某些经脉只提供其中一种属性防御；**1 点内功防御＝阴、柔、阳、刚防御各 +1**（由内功和经脉提供的即此类）。
- 原文结论：因内功防御获取方式多样，游戏后期相同装备条件下，内功角色通常可比外功角色抵御更高的攻击力（原文表述为"造成更高的伤害……可以抵御更高的攻击力"）。

**边际与防御忽视**

- 防御并非越高越好：外防过 1 万、内防过 1000 后，每点防御提供的减免收益下降。
- 但九阴中存在**防御忽视**属性，实战不能只满足于 50% 减伤阈值——需堆更高防御，才能在面对带忽视的各路对手时仍保有 50% 减伤。

**外功招架 / 内功化解词条**（本节末尾引出，详见 6.5）：两条不太常见的属性词条，均为格挡时的减伤幅度，基础值 50；外功招架堆到 100 时，格挡敌方外功攻击可近乎完全免疫（伤害低于 0.5 时甚至不显示数值）；五品生活玉护腕特效触发时，可看到这两条属性数值堆到惊人的高度。

### 6.4 百分比忽视（原第 4 节）

（原文开头称"这段话的主要内容已经在'外防内防'部分提到过了"——即上文 6.2，本节为强调重述。）

再次强调防御计算逻辑：双方对战时，**先通过加减法计算出防御的固定数值，再按该数值对应的百分比伤害减免计算，最后通过加减法得到最终的百分比伤害减免**。

- 部分内功有特殊效果，可忽视一定**百分比**的防御：无妄功忽视 15% 防御、丐帮会意 5 层忽视 30%、少林会意 5 层忽视 15%。
- 注意：酒雨和血刀经所忽视的是外功防御**数值**，而非百分比。
- 宝物属性中"百分比忽视"也是重要属性：普通心魔宝物最高 2%，价值 750 的宝物最高 3%。

### 6.5 外功招架、内功化解（原第 5 节）

- **外功招架**：成功格挡对手外功攻击后，对手最终实际受到的伤害。
- **内功化解**：成功抵挡对方阴 / 柔 / 阳 / 刚内功伤害后显示的最终伤害。
- 格挡与化解的默认效果均为 **50% 减免**，且适用于**所有类型伤害**（包括娃娃和兵录带来的伤害）。
- 外功招架值：六内区通常显示 60 点——衣服 +10、武器忽视 10，实际仍为 50 点。
- 内功化解可由经脉提供；经脉中亦有"内功化解忽视"功效；武技"龙爪"的架招格挡成功后也可获得内功化解忽视。
- 另有**忽视招架减免**机制（按百分比计算），如君子会意 5。

### 6.6 娃娃与兵录（原第 6 节）

**共性**：两者伤害均不受任何加成影响，显示数值即实际伤害；也**不受防御减伤**（无论外功伤害减免还是阴柔阳刚伤害减免都不起作用）；但可被招架 / 化解及减伤特效（护体罩、内功特效等）防住——外功吃外功招架克制，阴柔阳刚吃内功化解抵销；无妄防御姿态、神机二阶段内功特效、城管会意五阶段特效等也可减伤。

**娃娃**：外功伤害与抵消均受相关修为等级影响——每级只获得该属性 1/10 的加成。例：玉等级升到 10 级，外功伤害 +333 点，实际最终伤害只提高 33.3 点（取整 33）。外功抵消同理。

**兵录**：兵器招式中的兵录伤害最接近真实伤害，仅受对手外功招架 / 内功化解及减伤特效影响。例：用 1-1 的飞镖攻击外功防御 1 万的对手，伤害值 454 时总伤害 = 454 + 1 = 455；若对方开满层罩子，则 454 × (1 − 0.75) = 113.75，取整 114。

**抵消差异**：娃娃伤害会被娃娃自身抵消，兵录伤害则不会。

- A 攻击 B：A = 454 兵录 + 150 娃娃，B 有 100 点抵消 → 总伤害 454 + (150 − 100) = **504**。
- A = 454 兵录 + 50 娃娃，B 有 100 点抵消 → 娃娃部分 50 − 100 = 0（不足抵扣归零），实际伤害 0 + 454 = **454**。

**结论**：考虑士兵（兵录）与娃娃的伤害时，兵录的实际攻击力效果更高——娃娃可被抵消，兵录不能。
