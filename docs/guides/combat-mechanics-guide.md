## 一、霸体三类型总览

角色霸体分三种：**白霸体、黄霸体、红霸体**。

| 类型 | 特性 | 克制关系 |
|---|---|---|
| 白霸体 | 对抗机制与黄霸体大体相近 | 眩晕（晕眩）及类似眩晕的强力控制技能可打断 |
| 黄霸体 | 同白霸体 | 同上 |
| 红霸体 | **不受任何控制效果影响**——眩晕、击飞、击退、点穴、定身等均无法打断红霸体状态下的动作 | 无法被打断 |

**战场定位**：红霸体招式在对决和群战中优势极大，能无视敌方控制强行打出伤害或突进。

## 二、白 / 黄霸体的携带与克制

**携带来源**（原文口径较笼统）：部分门派或江湖武学中的特定起手式、实招或怒招带黄霸体效果（例如某些套路中的收招或出招阶段）。

**可打断 / 克制黄霸体的武学举例**：

| 武学 | 招式 | 效果 |
|---|---|---|
| 古谱太极拳 | 部分招式 | 可眩晕黄霸体 |
| 青云掌法 / 蚀骨摧心掌 | 天雷震地 | 出招第一击可眩晕黄霸体（对未格挡目标有效） |
| 大力金刚指 | 一弹指顷 | 点穴定身，若未被招架可强行控制 |
| 雪斋剑法 | 寒心恨雪 | 附带僵直效果，可打断黄霸体 |

## 三、红霸体武学举例

- **落英飞花剑 / 风花雪月**（俗称"大风车"，君子堂或相关武学）：经典红霸体——释放无需积蓄怒气，伤害高，且可结合轻功。
- **雪斋剑法**：部分核心招式自带"无敌红霸体"。
- 其它各类古谱、镇派及江湖武学中带霸体标识的高阶实招 / 怒招。
