## 一、官服自走链定版（对既有认知的三处修正）

### 1.1 触发时序真相：自走是**按下瞬间的本地决策**，受理簇只是兜底

88 次施法逐例对齐 211→首条 m15 state7→受理簇到达（见 tmp/rush_gap 统计）：

| 模式 | 样本 | 时序 |
|---|---|---|
| **按下即走** | 7 例（150.6/267.3/358.1/535.8/572.0/597.1/607.4） | m15 state7 与 211 **同毫秒**，簇 +43ms 后才到 |
| 簇到即走 | ~30 例 | walk_dt ≈ clu_dt ≈ +0.042~0.05s（=RTT；簇到后同拍起走） |
| 延迟起走 | 少数（+0.5~2.4s） | 先前动作未结束（跳跃/出招位移收尾后起走） |
| 不走 | 7 例 | hyjf07 点地族 / 已在射程内直收 |

**结论**：客户端按下时本地判「超射程 + CanRush → 接近」，多数情况毫秒级起走
（预选好目标时）；簇到达是第二武装点。**受理簇字节形态不是本服不自走的
充分解释**——簇四帧官服/本服已逐字节同构（CurSkillID(462)→CurSkillTarget(629)
→m25[30000,skill_pause]→m707[15]，+42ms 状态四连 586[5]/645[1]/646[1]/750[20]）。

### 1.2 走踢帧证伪：0x21(91B 双条目) 是 m15 的**回显应答**，不是驱动指令

32.642 案例：客户端 m15 state7 ×2（双帧起跑，dest=目标 xz、速度 4.5、
intent 0xA0000F01）→ 服务端 **+155ms 回 0x21 len=91 双条目**：obj=玩家
(0x070383e6,0x563e4e)，两入口 dest≈目标位 (947.83,1028.59)（微偏重复）、
slot3=4.689 常量、speed=4.5、orient=-π、尾槽 5.5/9.8、intent=0xA0000F01。
267.3 案例同形（码185）。在途每拍 m15（~2.2s）→ 0x21 len=47 单条目回显
（码219/220）。**官服没有"踢帧"**——rush_cast.go 的 rushWalkKickFrame
（+155ms 主动双入口 0x21 指望驱动客户端走）方向反了：客户端没走时它只是
被当回显吃掉（三轮真机「踢帧被吃但不执行」的真正原因）。echoPlayerMoveIntent
才是正确实现；走踢帧与「时钟对先行」hack 应撤。

### 1.3 选靶 0x28 详情帧证伪

- 30.456 的 0x28(47) 属于**另一个 NPC** obj(0x0700014b,0x150)（monm031300，
  State=walk，posA=(947.9,48.75,992.0)）——发出时间在 0x07 选靶 **前 374ms**，
  与选靶无关（0x28 是官服对移动中 NPC 的 1~2s 节奏周期刷新，全场 279 帧）。
- 官服选靶（0x07 + 431）只回 **416/417 双帧**（LastObject/AutoSelectObject，
  逐字节与我们 writePlayerTargetLocked 同构）。
- **自走目标 0x07018099 全场 1271s 没有收到过任何 0x28/0x1F/0x31**，客户端
  照样自走冲刺——目标 0x28 详情不是接近前提（3de3115 的按需重发假设不成立，
  可撤）。

## 三、真差集（按嫌疑排序）与修复批次

### P0 —— 本服真机会话取证（已完成，2026-11-12 补录+二轮修正）

数据：`E:\Workspace\project\game\9yin_server-go\captures\local`（11-12 凌晨五会话，

用户口径：**点击地面/地图都会走，远距按压冲锋不自走**。

**一轮结论（已修正）**：曾把 49268@296/51859@1212 的 27m/25.8m 走判为
「按压后即时自走、3~5 帧被打断」。二轮逐帧复核修正为：

  dest=目标坐标的真接近走 @296（**迟来的武装**），沿线推进 8.4m 后被
  0x3000 反向走打断（与官服 f.pcapng「拉回」同形）。接近**会**武装但
  迟、且走不远。
- 65148：21.3m 按压@75 后仅有 0.5m 噪声步（跳跃落地的收步，非接近），
  之后 state=5 冻结；27.2m 按压@443 后**零走**。多数按压零接近走。

  会把已武装的走拽回按压点）→ +600ms c61 接近冲刺（客户端从不执行）。
- 按压路径逐项字节核对**全部与官服一致**：受理簇四帧、m25/707、
  CurSkillTarget 三方 id 一致（选靶=211=簇帧）、玩家 GRushRange=5/

  MoveSpeed）。速度族全错值——接近决策/表现是否受其影响待排除，但
  必须先改对。
- 客户端本地 skill_static：hyjf02 CanRush=1 且 **RushRange 缺列**（hyjf07
  =30）——官服同文件同缺列仍会走，非单因；「缺列→不限射程→认为已就位
  →微步」假说存疑（官服反例）。
- 工具缺口：裸流 tap **无时间戳**，无法把「迟来武装/8.4m 中断」对到
  S2C 到达帧——capture_dump 建议改录 [ts u64][len u32][frame] 或落 pcapng。

### 认知修正（记录在案）

- **id 高字节不是类型位**：官服 obj/own 是全局顺序计数器，玩家与 NPC 双族
  混用（技能包玩家=0x070383e6/own 0x563e4e；登录包玩家=0x1105c0e3/own
